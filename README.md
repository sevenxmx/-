# 🎱 走位之巅（多手机共享版）

适用：宝塔面板 PHP 5.6 + MySQL 5.6.50
功能：V2.1 全部 11 项 + 服务器多人共享数据。

## 部署文件
- index.php
- config.php
- style.css
- app.js
- install.sql（可选：手动建表脚本）
（BilliardCalendar.html 是旧单机版，不需要上传）

## 部署步骤
1. 在宝塔面板创建网站，PHP 版本选择 5.6。
2. 在宝塔面板创建 MySQL 数据库（例如 billiard_db），并创建/授权数据库用户。
3. 将以上文件上传到网站根目录（install.sql 可选，不上传也可以）。
4. 编辑 config.php，填写：
   - BC_DB_HOST：数据库地址，默认 127.0.0.1
   - BC_DB_PORT：端口，默认 3306
   - BC_DB_NAME：数据库名
   - BC_DB_USER：数据库用户名
   - BC_DB_PASS：数据库密码
5. 手机浏览器访问网站首页（index.php），首次访问会自动建表。
6. 多台手机打开同一个网址即可共享同一份数据。

## 数据说明
- 所有人物、比赛、打卡均保存在 MySQL。
- 刷新页面、换手机、清浏览器缓存都不会丢失。
- 头像照片会自动压缩为 256px 左右再上传，控制体积。
